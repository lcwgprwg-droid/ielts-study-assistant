# 创建你的私有 IELTS 教练

1. 在 ChatGPT 网页打开 **Explore GPTs → Create**（或访问 `https://chatgpt.com/gpts/editor`）。
2. 选择 **Configure**，名称填入「IELTS Atelier · 雅思学习教练」。
3. 将 [IELTS_Atelier_GPT_Instructions.md](IELTS_Atelier_GPT_Instructions.md) 的全文粘贴到 **Instructions**。
4. 不需要配置 Actions、API Key 或外部知识库；将可见范围设为 **Only me / 仅自己**，然后保存。
5. 打开这个 GPT，并固定只用其中一条「雅思学习」对话。首次按它的提问填写目标。
6. 每次说「结束本次学习」后，复制它输出的 JSON 学习记录卡。在本站「导入学习记录」中粘贴即可更新可视化报告。
7. 将该 GPT 的分享链接复制到本站「目标与备份 → 私有 GPT 链接」；之后网页的「开始 ChatGPT 学习」按钮会直接打开它。

ChatGPT 订阅仅在 ChatGPT 网页内消耗；网页仪表盘不读取、不保存、也不调用任何 API Key。
